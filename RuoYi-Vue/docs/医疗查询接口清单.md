# 医疗查询接口清单

来源文件：`大数据查询结果模板(1)(1).xlsx`

## 接口设计

保险公司前端只调用统一查询入口，页面选择不同 `queryType` 表示不同医疗数据接口。

```http
POST /company/api/medical/query
```

请求体：

```json
{
  "queryType": "medical_all",
  "queryParams": {
    "name": "张三",
    "idCard": "430102199001018888"
  }
}
```

可选接口列表：

| queryType | 查询名称 | 模板来源 | 主要返回字段 |
| --- | --- | --- | --- |
| `medical_all` | 医疗大数据 | 医疗大数据 | 医疗就诊机构、就诊科室、就诊类型、就诊日期、诊断 |
| `medical_insurance` | 医保信息 | 医保信息 | 医保区划、单位名称、人员类型、参保状态、险种类型、就诊记录、报销费用金额 |
| `medical_record` | 电子病历 | 电子病历 | 基本信息、入院记录、出院记录、手术记录、影像检查报告 |
| `medical_order` | 医嘱信息 | 医嘱信息 | 就诊日期、医院、药品名称、发药量规格、诊断日期、科室、诊断名称、就诊类型 |
| `medical_image` | 影像信息 | 影像信息 | 报告时间、报告类型、就诊类型、影像号、检查日期、影像学表现、影像学诊断、报告医生、医院、科室 |
| `medical_surgery` | 近期手术 | 近期手术 | 手术日期、术前诊断、术中诊断、手术名称、手术者、麻醉方法、麻醉者、手术经过 |
| `medical_exam` | 体检信息 | 体检信息 | 项目名称、科室、体检小结、报告日期、报告医师、体检医院 |

## 当前落地方式

- `biz_query_price` 保存接口编码、名称、单次费用和启停状态。
- `/company/api/medical/query-types` 返回已启用接口，供页面下拉选择。
- `/company/api/medical/query` 接收 `queryType + name + idCard`，统一走鉴权、计费、日志、数据源查询和脱敏。
- 真实上游未接入前，`MockMedicalDataSource` 按 `queryType` 返回与模板对应的样例数据。
- `sql/medical_query_interfaces.sql` 可用于把 7 类接口初始化到数据库。

## 后续真实接口接入

真实接口接入时，优先保持前端和保险公司调用合同不变，只替换后端数据源实现：

1. 根据 `queryType` 路由到对应上游接口。
2. 将上游字段转换成平台统一返回结构。
3. 返回前执行脱敏。
4. 查询成功后记录日志和费用流水。
