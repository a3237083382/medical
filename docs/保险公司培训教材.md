# 保险公司平台培训教材

## 运营人员

### 日常开户

1. 进入保险公司管理。
2. 新增保险公司，填写公司名称、联系人、联系电话、登录账号。
3. 保存后系统生成 `AppKey` 和 `AppSecret`。
4. 通过安全渠道向保险公司交付密钥和接口文档。

### 充值审核

1. 保险公司提交充值申请。
2. 运营人员在充值管理中查看待审核记录。
3. 确认线下公对公到账后审核通过。
4. 系统写入余额变更和费用流水。

### 日志与费用核对

1. 查询日志用于核对每一次接口调用。
2. 费用流水用于核对充值、扣费、退款或冲正。
3. 不允许删除查询日志和费用流水。

### 精准延时查询处理

1. 进入业务管理中的“精准延时查询”。
2. 筛选未上传请求，核对公司名称、姓名、身份证号和提交时间。
3. 点击“上传/处理”，可以导入 Excel，也可以手工新增结果明细。
4. 点击“保存草稿”只保存内部处理进度，保险公司仍只能看到处理中。
5. 点击“上传完毕”后，保险公司可查看结果，系统按结果状态确认费用。
6. 未查得结果填写说明后可上传完毕，本次不扣费。
7. 已上传结果允许修正，必须填写修改说明，系统记录修改人和修改时间。
8. 在保险公司管理中点击“日志”，可分别查看该公司的实时查询日志和精准延时查询日志。

### 批量精准延时提交说明

1. 保险公司可以通过 `POST /company/api/delayed-query/submit-batch` 一次提交多个人员。
2. 每个人员仍生成一条独立精准延时请求，后台处理方式不变。
3. 已有未完成请求的人员会返回原请求编号，不会重复创建，也不会重复预留额度。
4. 新创建的请求会逐条预留本月服务额度，上传完毕后再按结果状态确认费用。

## 系统管理员

### 接口配置

1. 检查 `/api/v1/**` 已由签名拦截器保护。
2. 检查 Redis 可用，确保 `Nonce` 防重放生效。
3. 真实数据源开通后，在配置中填写数据源地址并设置路由。

### 数据源维护

1. 默认使用 `mock` 数据源完成开发和测试。
2. 湖南数字产业集团接口开通后，启用 `digital` 数据源。
3. 数据源不可用时，系统按配置回退到默认数据源或返回明确错误。

### 常见故障

| 现象 | 排查方向 |
| --- | --- |
| 返回 401 | 检查 AppKey、签名、时间戳、Nonce |
| 返回 4001 | 检查保险公司余额 |
| 返回 4003 | 检查查询价目是否启用 |
| 精准延时提交失败 | 检查姓名、身份证号是否为空，以及本月服务额度是否足够预留 |
| 精准延时结果不可见 | 检查是否已点击“上传完毕”，仅保存草稿不会对保险公司可见 |
| 返回 5001/5002/5003 | 检查数据源配置和外部接口可用性 |

## 验收准备

正式培训和试运行需要等真实数据源、服务器部署、保险公司联调名单和上线窗口确认后进行。
