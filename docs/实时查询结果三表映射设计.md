# 实时查询结果三表映射设计

## 1. 输入与记录边界

- 外部查询请求使用 `sfzhm`、`startdate`、`enddate`。
- 外部返回的 `res` 数组按元素逐条处理，每个元素对应一次就诊。
- 不按身份证号、医院或日期合并记录，保证同一人在时间范围内的多次就诊分别展示。

## 3. 输出表规则

### 基本信息表

每一次就诊都生成一张基本信息表，字段为：序号、身份证号码、姓名、性别、出生日期、就诊时间、就诊类型、医院名称、总费用、原始疾病编码、原始疾病名称、记录类型。

### 电子病历表

仅当就诊类型为“住院”时生成，字段为：入院日期、出院日期、入院诊断、出院诊断、入院情况、治疗结果、主诉、现病史、既往史、医嘱。

### 医学影像检查表

仅当就诊类型为“住院”且至少一个影像字段有值时生成，字段为：报告日期、科室、部位、影像表现、影像诊断。

## 4. 空值与显示

- 空字符串、`null` 和缺失字段统一显示为空，不使用 `undefined` 或 `null` 文本。
- 日期时间统一输出 `yyyy-MM-dd HH:mm:ss`；只有日期的字段保留 `yyyy-MM-dd`。
- 每条就诊记录独立显示表格标题和就诊序号，避免不同就诊内容混淆。
- 身份证号按当前测试页面要求完整显示；正式对外接口仍应按生产脱敏策略处理。
