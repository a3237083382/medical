## 验证策略

每完成一个可前置任务，执行对应验证：

- 后端工具、拦截器、数据源路由、统计服务：运行 `mvn -pl ruoyi-business clean test`。
- 后端接口编译：运行 `mvn -pl ruoyi-admin -am -DskipTests compile`。
- 前端页面：运行 `npm run build:prod`。
- 文档和示例：检查文件存在、关键接口路径、签名头、示例命令和培训目录。
