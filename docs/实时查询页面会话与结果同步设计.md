# 实时查询页面会话与结果同步设计

## 目标

1. 页面刷新后保留已验证的保险公司 AppKey。
2. 关闭页面后不保留 AppKey，下次进入必须重新接入。
3. 管理系统上传精准延时查询结果后，保险公司查询页面自动同步历史状态、结果详情和未读通知。

## 方案

### AppKey 会话

- 使用 `sessionStorage` 保存 AppKey，键名为 `medicalAppKey`。
- 页面初始化时读取并自动执行现有 AppKey 验证流程。
- 不使用 `localStorage` 保存 AppKey，避免跨页面长期留存凭证。
- 接入失败时清除会话值。

### 结果同步

- AppKey 接入成功后启动单一轮询定时器，间隔 5 秒调用现有历史接口和额度接口。
- 页面不可见时暂停轮询，重新可见时立即同步一次并恢复轮询。
- 以请求记录的状态、结果可见标识、上传时间和结果摘要组成变化判断。
- 检测到后台上传结果后复用现有渲染函数，刷新列表、详情入口、通知和查询状态。
- 页面重新接入或离开页面时清理定时器，避免重复轮询。

## 验证标准

- 接入 AppKey 后刷新页面，页面自动恢复“已接入”，无需再次输入。
- 关闭页面后重新打开，AppKey 输入框为空且页面要求重新接入。
- 管理端上传结果后 5 秒内，页面历史记录状态变为“已上传”，并出现结果通知。
- 后端不可用时轮询错误不阻塞页面操作，下一周期仍可继续同步。
