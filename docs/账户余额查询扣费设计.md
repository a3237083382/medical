# 账户余额查询扣费设计

## 目标

充值审核到账的 `biz_insurance_company.balance` 作为实时单人和实时 Excel 批量查询的唯一可用额度，不再用月度额度拦截这两类查询。

## 扣费规则

1. 查询提交前按命中价原子扣减账户余额；余额不足时拒绝，不创建可执行查询。
2. 数据源返回命中时保留实际命中费用；未命中或数据源失败时退回预留金额。
3. 批量查询一次性原子扣减全部新查询的预留费用，避免逐行扣费造成部分提交。
4. 每次扣款、退款保留原有查询日志和请求状态。

## 页面显示

`/company/embed/medical/usage` 的 `remaining` 改为账户余额，页面提示和本次可用额度与实际扣费口径一致。

## 验收标准

- 充值审核后余额为 1000 元时，费用 5 元的批量查询可以提交。
- 批量预估费用超过余额时整体拒绝，余额不发生变化。
- 命中后余额减少命中价，未命中/失败后余额恢复。
- 余额、门户显示和 index 显示来自同一公司账户。
